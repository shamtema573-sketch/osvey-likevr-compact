# Освей · LikeVR

Статическая презентация со встроенным расчётом и отдельный калькулятор. Обе страницы используют общую конфигурацию цен.

- `index.html` — презентация: проект, сценарий, варианты, калькулятор, кейсы и контакты.
- `calculator.html` — отдельный калькулятор.
- `config.js` — цены, рекомендуемые комплектации, срок, контакт.
- `app.js` и `styles.css` — поведение и оформление.

Для локального просмотра откройте HTML в браузере или запустите в папке `python3 -m http.server 8000`. Переходы поддерживают стрелки, нажатия на пункты и свайпы вне калькулятора.

Презентация открывается с утверждённой обложкой с увеличенным изображением самолёта. В разделе «Сценарий» вид из кабины и показ на стенде помечены как концепты.

Telegram открывается по ссылке, телефон и почта указаны текстом. Контакты редактируются в `config.js`. В `assets` лежат оптимизированные изображения из материалов сделки. Перед внешней публикацией согласуйте использование изображений и предложения.

## GitHub Pages

После согласования положите файлы в корень выбранного репозитория. Сохраните `.nojekyll` и папку `assets`. В Settings → Pages выберите публикацию из ветки и папки корня. Отдельный калькулятор будет доступен по пути `calculator.html`, встроенный — `index.html#calculator`. Сборка и сервер не нужны.
